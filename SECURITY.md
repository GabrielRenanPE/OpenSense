# Segurança

O OpenSense interage com hardware e executa operações limitadas como root por meio de auxiliares. O modo Manual não oferece monitoramento térmico contínuo. A autorização de resfriamento sem senha vale para qualquer usuário de sessão local ativa; isso é uma escolha explícita do pacote.

## Relatar vulnerabilidades

Evite publicar credenciais, dados pessoais ou detalhes exploráveis em uma issue pública. Se o mantenedor tiver habilitado Private vulnerability reporting no GitHub, use Security → Report a vulnerability. Se essa opção não existir, solicite um canal privado ao mantenedor pelo perfil do LinkedIn indicado no README, sem enviar detalhes sensíveis inicialmente. Não há prazo de resposta ou suporte comercial garantido.

## Escopo

A série 0.6.x é o foco atual de manutenção, sem promessa de atualizações de segurança para versões anteriores. Inclua a versão, a operação afetada e uma reprodução que não coloque hardware em risco. Não execute testes destrutivos para comprovar um relatório.

Os testes automatizados não substituem auditoria de segurança, teste de firmware ou validação de compatibilidade.
